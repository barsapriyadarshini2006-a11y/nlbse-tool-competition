
# MADE-WIC: Multiple Annotated Datasets for Exploring Weaknesses In Code and Replication Package

This package contains the MADE-WIC dataset and the code used to build it. It is organized into two directories:

- Dataset: contains the three CSV files that form the MADE-WIC dataset, organized into the respective folders such that they are easier to handle.
- Replication: contains the code needed to build the dataset. Further details are given in a specific README file inside the folder.
